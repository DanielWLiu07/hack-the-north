01 · The core loop

Room ↔ Pi ↔ Laptop

Three transports, each chosen for the shape of its traffic. Ask-once traffic is HTTP; the 50 Hz firehose is a WebSocket; physical action is the arm. This link must work with no internet at all — that's why nothing here routes through a cloud broker.

02 · Outside the room

Where Elasticsearch, Sentry and AWS attach

Every cloud connection is made by the laptop, and almost all of them are outbound. The one thing that would normally need an inbound hole — webhooks — is turned around with a queue.

04 · The frame chain

Two unit conversions, and the one that is a trap

Read from Bracket Bot's actual code. Their depth module and their odometry module disagree about what X and Z mean — compose them naively and every cloud is rotated 90°, which only shows once the robot turns, so it reads as drift rather than as a bug.

06 · The executor

A diff is not a list of moves — it is a dependency graph

Naively executing a diff in file order fails immediately: you cannot place a mug where a book still sits. And two objects that swap places form a cycle, which needs somewhere to put one of them — which is exactly what git stash means.
