# Housebot / Roommate MVP

One sentence: a caretaker robot that can find a household object and physically point to it, with one curated move as the next milestone.

## P0

- User asks where an object is.
- Daniel's search identifies it and returns its last-known pose.
- Housebot Edge safely translates the job.
- Robot points at the location.
- UI reports success or an honest failure.

## P1

- Move one curated object to one known target.
- Re-observe and verify.

## Not before P0 works five times

- General tidying
- Git branches/merge/conflicts
- Multi-object planning
- LLM planning in the edge
- Camera relaying
- Remote public robot control
